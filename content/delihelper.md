# DeliHelper

**GitHub repository:** [AlexSmed/DeliHelper](https://github.com/AlexSmed/DeliHelper)


## Project Description

DeliHelper is a software project developed to demonstrate my programming skills and practical development experience.
And This Application is meant to be a easy and manageable place to hold recipes, important information and Routines for a
Resturant / Deli, so that the Employees have an easier time knowing what to do. it also uses Gemeni to Check Products
for Allergies.


## Technologies Used

- Java
- Javalin
- JPA / Hibernate
- PostgreSQL
- Maven
- JWT authentication
